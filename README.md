# Port Vesper

[![Rank](https://make.fun/badge/gta6-01/Baophan00/makefun-gta6-20261118/rank.svg)](https://make.fun/bounty/gta6-01)
[![Reward](https://make.fun/badge/gta6-01/Baophan00/makefun-gta6-20261118/reward.svg)](https://make.fun/bounty/gta6-01)

An original top-down open-world crime game for make.fun gta6-01. Port Vesper is a hand-authored city of street grids, sidewalks, buildings, a park and a waterfront, drawn on canvas with a camera that follows the player. Walk or drive with WASD, enter and exit cars with Space, sprint with Shift, aim with the mouse and click to shoot, and press E at mission markers.

The city runs on its own: civilian cars follow lanes and turn at junctions, pedestrians walk the pavements, and wanted level 0-5 brings chasing police cars and sirens. Health, ammo, money, the objective and the wanted stars live in the HUD alongside a minimap. Three short jobs - a parcel delivery, a store heist and a police escape - pay cash, and progress saves in localStorage. All sound is generated with WebAudio; the game ships no external media and makes no network requests.

## Run it

```
node serve.ts
```

Open the local address the server prints. Start a new game with Enter, or continue a saved one with C.
